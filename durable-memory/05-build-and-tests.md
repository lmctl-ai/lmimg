# Build and verification

Build with `scripts/sync-deps.sh`, `scripts/sync-sdk.sh --verify`, then `./test.sh`.
CMake builds the pinned codec archives, static Q8/non-HDRI ImageMagick C libraries,
the host, and the native oracle executable. Roboto bytes and stb_truetype are
embedded at build time. No font or kernel/data file is required at runtime.

Local Linux verification on 2026-10-23: all 17 test groups passed in 40.14 seconds,
with peak resident memory 2,119,916 KiB for the complete build/test command.
The final native suite has 92 active runtime assertions (not C assert macros), including
large finite rotation angles, quantized pixels, geometry, masks/selections, HSL/channel mixing/curves, morphology,
healing, text colors, alpha preservation, over/multiply/screen, statistics,
closed-form PSNR/SSIM, seven raster codec round trips, and GIF frame timing.
Ten DSL programs compile and run: two regressions and eight examples. Fifteen
error snippets must return exit 3, JSON, and exactly one stderr diagnostic.

The suite additionally verifies dependency commit objects and clean checkouts,
SDK bytes, exact version, generated/embedded/compiler signature parity, exact
embedded notices, platform linkage, byte-identical figure reruns, dry-run behavior,
usage/load codes, malformed budget values, a 64 MiB runaway, and the default
4096 MiB runaway under a Linux 6144 MiB virtual-memory ceiling.

The gallery checker validates committed and freshly generated images independently;
it does not use file modification times, which are unreliable after Git checkout.
Eight 900×520 PNGs and a 640×360 eight-frame GIF are regenerated by
`examples/render-all.sh`. The figures were opened and checked for visible effects,
legible labels, intact margins, and motion in both the first and middle GIF frames.

Static linkage is checked with ldd on Linux, otool on macOS, and objdump on Windows.
The scripting compiler is npm `@lmctl-ai/lmctl@0.2.369` in CI. Native tests keep
assertions active in optimized builds. ImageMagick caches cannot spill to disk.
