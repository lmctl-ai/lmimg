# Schema and image mathematics

`cpp/main.cpp` is the schema source. Literal typed registrations are parsed by `scripts/gen-schema.py` into `schema/lmimg.dsl.json`; CMake embeds those exact bytes. The tests compare generated bytes, embedded bytes, registry signatures and compiler signatures.

RGBA channels use normalized doubles at the interface and Q8 native storage. A color is quantized to the nearest byte, so normal rounding error is at most 0.5/255. Image coordinates/dimensions are pixels. Pattern expressions have normalized x,y in [0,1]; expression parsing is shared MIT code from the host family. No closures, lists or maps are needed. `cpp/expr.hpp` defines the exact supported function/operator grammar.

PSNR is `10 log10(1/MSE)` over all normalized RGBA samples, with +infinity for exact identity. SSIM uses Rec.709 luma (0.2126R+0.7152G+0.0722B), sample variances and actual paired covariance over one global window, with C1=0.0001 and C2=0.0009. Identity is 1; negative correlation can give negative SSIM. It is not the windowed/multiscale variant. Dimensions must match.

The histogram has 256 bins of rounded arithmetic-mean RGB intensity and exports `bin,count` CSV. Statistics use population variance per normalized channel. Crop rejects out-of-bounds regions; invalid operations raise run errors. All supplied float arguments must be finite. Native pixel tests use known answers and quantization-aware tolerances rather than testing only file existence.

Curves are piecewise-linear control pairs built with `img.curve().point(x,y)`; x must increase from 0 to 1, and all coordinates lie in [0,1]. HSL adds hue in degrees and scales saturation/lightness. `channelmix` takes a row-major 3×3 RGB matrix; alpha is preserved. Masks multiply existing alpha by the mask's weighted RGB luma and alpha. Rectangular selections clear alpha outside their bounds. Layer stacks snapshot their inputs on add; over/multiply/screen/overlay/difference/darken/lighten/addition/subtract use straight-alpha source-over compositing, with opacity applied to source alpha.

Perspective maps the source unit-square corners to the supplied normalized quadrilateral and inverse-samples on the existing output canvas. Lens distortion samples around the image center with radial factor `1 + d*r²`; it is a compact single-coefficient model. Healing-lite replaces a rectangular region's RGB with the mean RGB of its surrounding boundary band, preserving alpha. It is intentionally a local blemish correction, not content reconstruction. Morphology uses square neighborhoods with replicated edge samples and supports erode, dilate and median with radius 0–16.

Sepia uses the RGB matrix rows (0.393,0.769,0.189), (0.349,0.686,0.168),
(0.272,0.534,0.131), mixed with the source by strength/100 and clipped.
Strength 0 is identity; 100 is the full warm-tone matrix. Alpha is preserved.

## Added in 0.1.2

`threshold(level)` sets RGB to 1 where Rec.709 luma ≥ level, else 0. `invert` is 1−RGB. `normalize` stretches each RGB channel from its own min/max to [0,1] (a constant channel is left alone). `equalize` builds a 256-bin luma histogram, maps each pixel through the normalized cumulative histogram (first occupied bin → 0, last → 1) and scales RGB by new/old luma. `colormap(name)` interpolates luma linearly between equally spaced anchor colours (gray 2, heat 5, viridis 5, coolwarm 3 anchors). `curves_rgb` applies one control-point curve per channel; `curves(c)` is `curves_rgb(c,c,c)`. `img.hald(level)` lays out the standard Hald CLUT (index i: r = i mod n, g = (i / n) mod n, b = i / n², n = level², side = level³); `clut(h)` samples it trilinearly. `img.text_width` sums per-glyph advances rounded exactly as `text()` does and returns the widest line. Blend `divide` is min(1, cb/cs) with cs = 0 → 1. `hash(x,y,seed)` mixes the 64-bit patterns of its arguments (splitmix64 finaliser) into [0,1); `noise(x,y,seed)` is value noise on the integer lattice with a quintic fade. `blur` premultiplies RGB by alpha, convolves all four channels, and un-premultiplies. `heal` fits c + gx·dx + gy·dy per channel to the ring by least squares. `perspective`/`lens` sample bilinearly on premultiplied RGBA.
